## Roles

Organization membership and API access levels:

| Role | Who gets it | Satisfies |
|---|---|---|
| `owner` | User who creates the organization | owner, admin, developer, viewer |
| `admin` | Organization administrator | admin, developer, viewer |
| `developer` | Default role on team invite | developer, viewer |
| `viewer` | Read-only organization member | viewer |
| `member` | Console member | Console access only. Not a public API role. |

Creating an organization grants the `owner` role. A team invite grants `developer` or `viewer`. Viewer tokens cannot send messages, execute handoffs, resolve conversations, or modify contact groups.

## Public API entitlement

Public API access and rate limits are governed by organization plan entitlements.

| Plan family | PublicAPI | PublicAPI rpm | Monthly credits | Data sources | Channels |
|---|---|---|---|---|---|
| `free` | false | 0 | 200 (hard stop) | 1 | 2 |
| `starter` | false | 0 | 1500 (pay as you go) | 4 | 4 |
| `growth` | true | 60 | 5000 (pay as you go) | 10 | 8 |
| `scale` | true | 300 | 12000 (pay as you go) | 25 | unlimited |
| `enterprise` | true | unlimited | unlimited | unlimited | unlimited |
| lookup failure | false | 0 | 200 (hard stop) | 1 | 2 |

Free and Starter plans do not include API access (`403 public_api_disabled`). Growth, Scale, and Enterprise plans provide full API access according to rate limits. An unrecognized plan or entitlement lookup failure uses the fail-closed default (`PublicAPI` false).

## Scopes

Grantable on a key or OAuth client. Empty scopes are rejected.

`agents:read`, `agents:write`, `conversations:read`, `conversations:write`,
`contacts:read`, `contacts:write`, `groups:read`, `groups:write`,
`whatsapp:send`, `campaigns:write`, `webhooks:read`, `webhooks:write`,
`ask_agent`, `datasources:read`, `datasources:write`, `analytics:read`,
`billing:read`, `mcp`.
