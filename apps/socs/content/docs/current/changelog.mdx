Additive fields are allowed in v1. Removing or renaming a field is a
`/v2` change.

## 2026-09-24 — Waves 0–6 (v1)

- Wave 0: Port B listener, `GET /healthz`, Keto roles, `PublicAPI`
  entitlement, OTLP traces, inbound Redis bridge.
- Wave 1: API keys (`cnx_live_` / `cnx_test_`), `/v1/oauth/token`,
  JWKS, `/v1/me`.
- Wave 2: conversations + operator WS tickets.
- Wave 3: contacts, contact groups, WhatsApp template send, campaigns.
- Wave 4: webhook subscriptions, guest sessions, visitor WS.
- Wave 5: agents read, `ask_agent`, public `POST /mcp`.
- Wave 6: this OpenAPI, webhook/MCP docs, OAuth redirect allowlist.
