Host: `https://public-api.cerebronix.com`.

Additive fields are allowed in v1. Removing or renaming a field is a
`/v2` change.

## 2026-09-25

- `GET /v1/organizations` — retrieve organizations accessible to the authenticated token.
- Agent management: programmatic agent creation, prompt instruction updates, and knowledge source bindings.
- Knowledge data sources: website crawling, YouTube transcription ingestion, and plain text sources with PATCH and DELETE support.
- Channels & Analytics: channel health verification and organization analytics summaries.
- Billing APIs: read endpoints for credit balances, plan entitlements, and transaction ledgers.

## 2026-09-24 — Initial v1 Release

- Public API gateway launch (`https://public-api.cerebronix.com`) with health checks and distributed tracing.
- API key provisioning (`cnx_live_`) and OAuth 2.1 client credentials authentication (`/v1/oauth/token`, `/v1/me`).
- Conversation threads, message histories, and real-time operator WebSocket streaming.
- Contacts, customer groups, and WhatsApp business message dispatch.
- Webhook subscription management with cryptographic HMAC SHA-256 signatures.
- AI Agent reasoning endpoints (`POST /agents/{id}/ask`) and Developer Model Context Protocol (`POST /mcp`).
- Authoritative OpenAPI 3.0 specification publication.
