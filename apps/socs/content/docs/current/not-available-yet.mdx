The Cerebronix Public API currently provides programmatic access to AI Agents, knowledge data sources, conversations, channel bindings, analytics, webhooks, and the Developer Model Context Protocol (MCP).

## Upcoming Developer Capabilities

The following capabilities are actively planned for future API releases:

| Area | Planned Capability | Current Console Path |
|---|---|---|
| Knowledge Connectors | Direct binary file upload API | Manage via SaaS Console > Data Sources |
| Team & Invites | Programmatic member invitations | Manage via SaaS Console > Organization Settings |
| Billing & Payments | Programmatic payment method management | Manage via SaaS Console > Billing |
| GraphQL | Unified GraphQL query endpoint | REST endpoints currently available |

## Platform Boundaries

The official public interface of Cerebronix is served exclusively via:
- **Public REST API:** `https://public-api.cerebronix.com/v1`
- **Developer MCP Server:** `https://public-api.cerebronix.com/mcp`

Internal management endpoints, administrative session routes, and internal microservice interfaces are non-public and strictly protected.
