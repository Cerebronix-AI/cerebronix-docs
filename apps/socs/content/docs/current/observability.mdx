The Cerebronix Public API supports distributed tracing via the standard W3C Trace Context specification to enable end-to-end request correlation between your client applications and platform execution.

## Trace Context Propagation

Client systems can pass a standard W3C `traceparent` HTTP header with outgoing API requests:

```http
traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01
```

When provided, the platform extracts and preserves this trace context across agent processing, knowledge retrieval, and asynchronous event delivery.

## Diagnostic Attributes

Platform traces and diagnostic logs automatically correlate execution with:
- **`organization_id`**: The verified tenant organization identifier.
- **`actor`**: The authenticated API key or OAuth subject.
- **`channel`**: The target delivery channel (when processing channel interactions).

To assist Cerebronix support when troubleshooting failed or unexpected requests, provide your organization ID and the timestamp of the request.
