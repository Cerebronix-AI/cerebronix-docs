The Cerebronix Contacts and Groups API enables programmatic synchronization of customer identity records, demographic attributes, communication channel associations, and segmentation groups for targeted outbound campaigns and omnichannel messaging.

All contact endpoints are org-scoped under `https://public-api.cerebronix.com/v1/organizations/{organization_id}`.

---

## 1. Contact Management

### List Contacts
Retrieve contacts with optional keyword, country, city, language, and channel filtering.

```http
GET https://public-api.cerebronix.com/v1/organizations/{organization_id}/contacts
```

#### Query Parameters
- `q` (string): Keyword search against name, email, or phone.
- `country` (string): Two-letter ISO country code (e.g. `US`, `GB`, `IN`).
- `city` (string): City name filter.
- `language` (string): ISO language code (e.g. `en`, `es`, `hi`).
- `channel_id` (string): Filter contacts who interacted via a specific communication channel.
- `limit` (integer): Records per page (default `25`, max `100`).

```bash
curl -sS "https://public-api.cerebronix.com/v1/organizations/$ORG_ID/contacts?q=Alex&limit=10" \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

#### Response (`200 OK`)
```json
{

    {
      "id": "670987654321fedcba098765",
      "name": "Alex Mercer",
      "email": "alex.mercer@example.com",

      "city": "Seattle",
      "language": "en",

      "created_at": "2026-10-15T14:20:00Z",
      "updated_at": "2026-10-19T09:12:00Z"
```

### Create Contact
Create a new customer profile. Phone numbers must strictly adhere to **E.164 format** (`+[country code][subscriber number]`).

```http
POST https://public-api.cerebronix.com/v1/organizations/{organization_id}/contacts
```

### Request Body
```json
{
  "name": "Sarah Connor",
  "email": "sarah.connor@example.com",
  "phone": "+12125550144",
  "country": "US",
  "city": "New York",
  "language": "en",
  "marketing_opt_in": true
}
```

### Update Contact
Partially update an existing customer record.

```http
PATCH https://public-api.cerebronix.com/v1/organizations/{organization_id}/contacts/{id}
```

```bash
curl -sS -X PATCH "https://public-api.cerebronix.com/v1/organizations/$ORG_ID/contacts/$CONTACT_ID" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"marketing_opt_in": false, "city": "Los Angeles"}'
```

### Delete Contact
Permanently remove a customer record from the organization directory.

```http
DELETE https://public-api.cerebronix.com/v1/organizations/{organization_id}/contacts/{id}
```

#### Response (`200 OK`)
```json
{
  "status": "deleted"
}
```

## 2. Segmentation Groups

Contact groups allow you to organize customer contacts into targeted segments for promotional broadcasts and automated WhatsApp workflows.

### Create Contact Group
Create a group with an optional initial list of contact IDs.

```http
POST https://public-api.cerebronix.com/v1/organizations/{organization_id}/contact_groups
```

### Request Body
```json
{
  "name": "VIP Holiday Shoppers",
  "contact_ids": [
    "670987654321fedcba098765",
    "671987654321fedcba098766"
  ]
}
```

```bash
curl -sS -X POST "https://public-api.cerebronix.com/v1/organizations/$ORG_ID/contact_groups" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "VIP Holiday Shoppers",
    "contact_ids": ["670987654321fedcba098765"]
  }'
```

#### Response (`201 Created`)
```json
{
  "id": "grp_019234567890",
  "name": "VIP Holiday Shoppers",
  "contact_ids": [
    "670987654321fedcba098765"
  ],
  "created_at": "2026-10-19T22:15:00Z",
  "updated_at": "2026-10-19T22:15:00Z"
}
```

### Add Group Members
Append contact IDs to an existing group without overwriting current members:

```http
POST https://public-api.cerebronix.com/v1/organizations/{organization_id}/contact_groups/{id}/members
```

### Request Body
```json
{
  "contact_ids": [
    "671987654321fedcba098766"
  ]
}
```

---

## Validation & Compliance Rules

1. **E.164 Phone Format:** Phone numbers must start with `+` and country code with no spaces, dashes, or parentheses (e.g., `+12065550100`). Invalid strings fail with `400 invalid_request`.
2. **Deduplication:** Contacts are deduplicated per organization by phone number. Creating a contact with an existing phone number updates the existing record.
3. **Marketing Consent (`marketing_opt_in`):** Promotional WhatsApp broadcast campaigns require documented customer consent. Attempting to target contacts without `marketing_opt_in: true` halts outbound template delivery with `403 marketing_opt_in_required`.
