---
title: Billing
description: Read-only balance, entitlements, and transaction ledger.
---

Read access requires the `billing:read` OAuth scope (available to viewer, operator, and owner roles). Plan upgrades and payment method management are handled securely through the Cerebronix SaaS console.

```bash
curl -sS "https://public-api.cerebronix.com/v1/organizations/$ORG_ID/billing/balance" \
  -H "Authorization: Bearer $ACCESS_TOKEN"

curl -sS "https://public-api.cerebronix.com/v1/organizations/$ORG_ID/billing/entitlements" \
  -H "Authorization: Bearer $ACCESS_TOKEN"

curl -sS "https://public-api.cerebronix.com/v1/organizations/$ORG_ID/billing/transactions" \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

MCP equivalents: `get_usage_summary`, `get_billing_balance`,
`get_billing_entitlements`, `list_billing_transactions`. Credits for
`POST /agents/{id}/ask` are `public_ask_agent`. See
[Authorization](/docs/current/authorization) for plan families.
