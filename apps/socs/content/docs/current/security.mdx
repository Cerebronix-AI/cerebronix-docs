title: Security and Responsible Use
description: Security guidelines and credential best practices for the Cerebronix Public API.
---

The Cerebronix Public API enforces secure authentication via scoped API keys and OAuth 2.1 Bearer tokens over TLS (HTTPS). Browser session cookies and unauthenticated requests are strictly rejected.

<WarnNever>
Do not send `X-User-ID` or unverified custom headers as authentication. The Public API validates authentication strictly via the `Authorization: Bearer <token>` header or official API keys. Arbitrary actor or organization identity overrides are rejected by platform gateways.
</WarnNever>

## Credential Management

- **Keep Secrets Confidential:** Never commit API keys, OAuth client secrets, or webhook signing secrets to source code repositories, client-side frontend code, or public forums.
- **Rotate Compromised Keys:** If an API key or webhook signing secret is inadvertently exposed, immediately revoke and regenerate it from the Cerebronix SaaS console under Organization Settings.
- **Enforce Least Privilege:** Scope OAuth tokens and API keys strictly to the permissions required for your application (e.g., `agents:read` rather than administrative scopes).

## Vulnerability Reporting

If you identify a suspected vulnerability or security concern, please contact our security team immediately at `security@cerebronix.com`.
