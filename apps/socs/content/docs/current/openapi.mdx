---
title: OpenAPI Specification
description: Official OpenAPI 3.0 specification for the Cerebronix Public REST API.
---

The authoritative contract for the Cerebronix Public API is published as an OpenAPI 3.0 specification: `public-openapi.v1.yaml`.

You can download the specification directly to generate typed API clients (using OpenAPI Generator, Orval, or Fern) or import into tools such as Postman and Swagger UI:

- **Specification File:** [public-openapi.v1.yaml](/public-openapi.v1.yaml)
- **Base Production Server:** `https://public-api.cerebronix.com`

All public endpoints are versioned under `/v1/` and require HTTPS.
