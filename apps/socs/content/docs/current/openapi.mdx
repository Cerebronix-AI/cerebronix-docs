- **Transport Security:** Strict TLS 1.3 / HTTPS only. Plain HTTP connections are rejected.
- **Specification Version:** `1.0.0` (OpenAPI 3.0.3 compliant)

## Architecture & Browser Security Model

<Callout type="warn">
  **Browser Credential Protection & CORS Enforcement:**
  - **No Browser-Side Execution:** The Cerebronix Public API is engineered exclusively for **server-to-server** and backend service integration. Public authenticated endpoints (`/v1/oauth/token`, `/v1/organizations/...`, `/mcp`) intentionally do **not** emit wildcard or permissive Cross-Origin Resource Sharing (`CORS`) headers.
  - **Confidentiality Safeguard:** Client credentials (`client_secret`, API Key secret) and Bearer access tokens must never be embedded or executed in public browser code. Doing so would expose organization secrets to end users.
  - **Single Browser Exception:** The visitor session initialization endpoint (`POST /v1/guest/sessions`) permits cross-origin invocation solely for the embeddable Cerebronix Web Chat Widget from origins pre-registered in the organization's channel configuration.
  - **Interactive Explorer Operation:** This API reference operates in **read-only inspection mode**, providing copyable, sanitized code snippets in **cURL**, **TypeScript (Node.js)**, and **Python** for safe execution from your backend development environments or terminal.
</Callout>

## Authentication & Authorization Model

All requests to `/v1/organizations/{organization_id}/...` and `/mcp` require an RS256 Bearer access token minted via OAuth2 client credentials:

```bash
curl -sS -X POST "https://public-api.cerebronix.com/v1/oauth/token" \
  -u "ak_01923456789a:csk_live_01923456789abcdef0123456789" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials"
```

## 1. Authentication & Identity

### `POST /v1/oauth/token`
Mint an RS256 Bearer access token using API Key credentials.

- **Operation ID:** `createOAuthToken`
- **Authentication:** HTTP Basic (`client_id:client_secret`) or Form / JSON body
- **Rate Limit:** 60 RPM per client ID

```bash tab="cURL"
curl -sS -X POST "https://public-api.cerebronix.com/v1/oauth/token" \
  -H "Content-Type: application/json" \
  -d '{
    "grant_type": "client_credentials",
    "client_id": "ak_01923456789a",
    "client_secret": "csk_live_01923456789abcdef0123456789"
  }'
```

```typescript tab="TypeScript"
import axios from 'axios';

interface TokenResponse {
  access_token: string;
  token_type: string;
  expires_in: number;
  scope: string;
}

const response = await axios.post<TokenResponse>(
  'https://public-api.cerebronix.com/v1/oauth/token',
  {
    grant_type: 'client_credentials',
    client_id: 'ak_01923456789a',
    client_secret: 'csk_live_01923456789abcdef0123456789',
  }
);
console.log('Bearer Token:', response.data.access_token);
```

```python tab="Python"
import requests

response = requests.post(
    "https://public-api.cerebronix.com/v1/oauth/token",

        "grant_type": "client_credentials",
        "client_id": "ak_01923456789a",
        "client_secret": "csk_live_01923456789abcdef0123456789",
    },
)
response.raise_for_status()
token = response.json()["access_token"]
print("Bearer Token:", token)
```

## 6. Model Context Protocol (MCP)

### `POST /mcp`
Stateless HTTP POST JSON-RPC 2.0 endpoint implementing MCP protocol version `2024-11-05`. Exposes 30 curated platform tools for external AI agent harnesses. Mutating tools strictly enforce `"confirm": true` safeguard.

<Callout type="info">
  **MCP Transport Specification:**
  - **Protocol Standard:** JSON-RPC 2.0 over standard HTTP POST.
  - **Protocol Version:** `2024-11-05` (Fixed negotiation).
  - **Streamable HTTP (2025-03-26):** Server-Sent Events (SSE) streaming and `Mcp-Session-Id` session tracking are **not** implemented.
  - **Client Compatibility:** HTTP-capable clients (such as Cursor or custom LLM scripts) connect directly to `POST /mcp` with Bearer tokens. Stdio-only clients (Claude Desktop, Zed) connect via the documented local Node.js bridge (`mcp-bridge.mjs`).
</Callout>

- **Operation ID:** `invokeMCP`
- **Scope:** `mcp` | **Role:** `developer`

```bash tab="cURL"
curl -sS -X POST "https://public-api.cerebronix.com/mcp" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "ask_agent",
      "arguments": {
        "organization_id": "'"$ORG_ID"'",
        "agent_id": "'"$AGENT_ID"'",
        "input": "What are your business hours?",
        "confirm": true
      }
    }
  }'
```

## 7. Common Error Responses & HTTP Status Codes

All error responses return a standardized JSON object containing the error code:

```json
{
  "error": "code_string"
}
```

| HTTP Status | Error Code (`error`) | Root Cause & Resolution |
| :--- | :--- | :--- |
| `400 Bad Request` | `invalid_request` | Malformed JSON, missing mandatory fields, invalid URL, or failing regex validation. |
| `401 Unauthorized` | `invalid_token` / `missing_actor` | Bearer token is missing, expired, or failed signature verification against JWKS. |
| `402 Payment Required` | `insufficient_credits` | Platform credit pool is exhausted and plan does not permit overage billing. Top up credits via billing console. |
| `403 Forbidden` | `missing_scope` | Token lacks the specific OAuth scope required for the requested operation. |
| `403 Forbidden` | `insufficient_role` | API Key role is `viewer`, but the operation requires mutating role `developer`. |
| `403 Forbidden` | `public_api_disabled` | Organization subscription plan does not have programmatic API access enabled. |
