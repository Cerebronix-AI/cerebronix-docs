---
title: Authentication
description: API keys, client credentials, and OAuth 2.1 on Port B.
---

Public callers authenticate with a Bearer access token on
`https://public-api.cerebronix.com`. Mint that token from an API key or
an OAuth client. Cookies are not a public credential.

Oathkeeper overwrites `X-Actor-*` and `X-Org-ID`. Do not send those
headers as your identity. Forged actor headers are discarded.

## API keys

Create a key in the product **Developer** page (owner or admin). Free
and Starter orgs cannot mint keys (`403 public_api_disabled`).

- Production secrets start with `cnx_live_`
- Local Port B secrets start with `cnx_test_`

The secret is shown once. A revoked key cannot mint a new JWT.

## Client credentials

```bash
curl -sS -X POST https://public-api.cerebronix.com/v1/oauth/token \
  -u "$KEY_ID:$KEY_SECRET" \
  -d grant_type=client_credentials
```

Local:

```bash
curl -sS -X POST http://127.0.0.1:8010/v1/oauth/token \
  -u "$KEY_ID:$KEY_SECRET" \
  -d grant_type=client_credentials
```

Send the access token:

```bash
curl -sS https://public-api.cerebronix.com/v1/me \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

## OAuth 2.1 (Hydra)

Authorization-code + PKCE uses issuer `https://oauth.cerebronix.com`.
Redirect URIs must be HTTPS except loopback (`127.0.0.1` / `localhost`).
`javascript:`, private IPs, and userinfo URIs are rejected.

For MCP, you may request audience `cerebronix-public-mcp`. See
[Developer MCP](/docs/current/developer-mcp).
