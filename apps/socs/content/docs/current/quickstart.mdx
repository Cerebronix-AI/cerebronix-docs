---
title: Quickstart
description: Reach healthz, mint a token, and call GET /v1/me.
---

You need a Growth (or higher) org and an owner or admin who can open
**Developer** in the product. Free and Starter orgs cannot mint keys
(`403 public_api_disabled`).

Do not paste tokens or secrets into tickets or chat.

## 1. Confirm the host

```bash
curl -sS https://public-api.cerebronix.com/healthz
```

A healthy response is `200` with body `ok`.

```bash
curl -sS https://public-api.cerebronix.com/.well-known/jwks.json
```

## 2. Create an API key

In the product, open **Developer** and create an API key. The secret is
shown once. Production secrets start with `cnx_live_`.

Copy the key id (`client_id`) and the secret (`client_secret`).

## 3. Exchange the key for a token

```bash
curl -sS -X POST https://public-api.cerebronix.com/v1/oauth/token \
  -u "$KEY_ID:$KEY_SECRET" \
  -d grant_type=client_credentials
```

## 4. Call `/v1/me`

```bash
curl -sS https://public-api.cerebronix.com/v1/me \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

Unauthenticated `/v1/me` is `401`. Then list orgs the token can act on:

```bash
curl -sS https://public-api.cerebronix.com/v1/organizations \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

Bare `/v1/conversations` (no org) is `404`. Conversation and agent lists
are org-scoped — see [Conversations](/docs/current/conversations) and
[Agents](/docs/current/agents-and-ask).
