`GET /healthz` is unlimited and does not require an actor.

## Status codes you already see

| Code | When |
|---|---|
| `401` | Missing or invalid Bearer on `/v1/me`, org agents, `POST /mcp` |
| `403` | `public_api_disabled` (Free/Starter, or no `PublicAPI`) |
| `404` | Unscoped `/v1/conversations`, invalid resource identifier |

Tokens without the required scope are refused. Viewer tokens cannot
write. A revoked key cannot mint a new JWT.

Rate limits follow the `PublicAPI` rpm on
[Authorization](/docs/current/authorization). `/healthz` is not
limited.

Platform audit logging records authenticated administrative actions for compliance and security review.
