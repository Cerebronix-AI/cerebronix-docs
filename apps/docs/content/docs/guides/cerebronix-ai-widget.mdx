The Cerebronix AI Widget allows visitors to interact with your AI Agents directly on your website or within the operator console.

## In-Console Testing

Within the operator console, the chat bubble provides a live environment for testing agent interactions, prompt guardrails, and knowledge retrieval before going live.

## Embedding on Your Website

To embed the web chat widget on your public website:
1. Navigate to **Channels** in the operator console.
2. Select or create a **Web Chat Widget** channel.
3. Configure your widget title, branding color, and allowed domain origins.
4. Copy the provided script snippet and insert it into your website's HTML template before the closing `</body>` tag.

If the bubble is missing, you are not on the signed-in console, or a
client error replaced the page.
