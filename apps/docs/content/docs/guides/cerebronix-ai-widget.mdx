## Quick Embed Reference

To embed the widget on your public website, insert this asynchronous loader snippet immediately before your closing `</body>` tag:

```html
<script>
window.cerebronixWidgetConfig = {
  orgId: "your_org_id",
  channelId: "your_channel_id",
  themeColor: "#2563eb",
  welcomeTitle: "How can we help you today?",
  tagline: "Typically replies in seconds"
};
</script>
<script src="https://chat.cerebronix.com/loader.js" async></script>
```
