| **Update Model Parameters or Guardrails** | `owner`, `admin`, `developer` |
| **Modify Knowledge or Channel Bindings** | `owner`, `admin`, `developer` |
| **Test Agent in In-Console Sandbox** | `owner`, `admin`, `developer`, `viewer` |
