When you finish this page, you know Marketronix is a second product
surface, not part of the first-run agent path.

**Who:** `owner` or `admin` on an org that uses ecommerce.

## What ships here

The operator sidebar has **Ecommerce**. **Integrations** also has a
**Marketronix** Connect card. Do not mix "train an agent on a PDF" with
"create a Medusa product variant" on the same page.

## Phase D

Store setup, products, orders, promotions, inventory, and payouts stay
in Phase D. This page does not invent those screens.

If you only need the agent to answer from a catalog later, add a data
source first. Connect Marketronix when you are ready to operate a store.
