## The 4-Step Native Store Configuration Chain

To connect a Native Cerebronix Store to conversational AI agents, follow the deliberate 4-step sequence:

1. **Store Setup & Catalog Creation:** Navigate to **Ecommerce** (`/e-com` or `/store`) to complete the **Store Setup Wizard** (`/setup-wizard`) for fulfillment (Shiprocket), payments (Stripe/PayU), and warehouse locations. Create your product categories, options, and variant SKUs under `/products`.
2. **Integration Configuration:** Connecting the native store via the **Data Sources** console (`/datasources`) by selecting **Marketronix** automatically establishes the integration connection using platform authorization tokens. Alternatively, operators can configure the restored **Marketronix** integration card under `/integrations` with the store URL and publishable token.
3. **Data Source Vector Sync:** Ingest the product catalog into vector embeddings within the Knowledge Engine.
4. **AI Agent Store Binding:** In `/ai-agents/[id]`, select your store instance in the **Ecommerce Integration** radio picker, and check the synchronized catalog data source under **Knowledge Sources**.
