When you finish this page, you have opened **Integrations** and you know
which Connect cards the console shows.

**Who:** `owner` or `admin`.

## Prerequisites

An organization. Do not connect a production store on Docs Demo.

## Steps

1. Open **Integrations** (`/integrations`).
2. The page lists **HubSpot**, **Shopify**, **WooCommerce**, **Magento**,
   and **Marketronix**, each with **Connect**.
3. If you start Connect and the OAuth host blocks the flow, stop.

![Docs Demo Integrations. HubSpot, Shopify, WooCommerce, Magento, and Marketronix each have Connect.](https://docs-cdn.cerebronix.com/guides/integrations/01-list.png)

Expected result: you can name the five cards. A completed OAuth is not
required for this page.

Marketronix store setup (products, orders) is a separate track.
