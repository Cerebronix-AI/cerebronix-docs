When you finish this page, you have opened **Data Sources** and you know
the Free limit.

**Who:** `owner`, `admin`, or `developer`.

## Prerequisites

An organization. Free plans allow one data source. Do not upload customer
PII.

## Steps

1. Open **Data Sources** in the sidebar.
2. Use **+ Add** to add a public URL or a small dummy file.
3. Wait until the source shows as ready. If index fails, retry once.

Expected result: dashboard **Data sources** moves from `0 / 1` to `1 / 1`
on Free.

If the source list never appears, reload once. Test answers from
**AI Agents** after you bind the source.
