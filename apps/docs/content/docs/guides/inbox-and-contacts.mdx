When you finish this page, you have opened operator **Chat** and
**Contacts** and you know the empty states.

**Who:** `owner`, `admin`, or `developer`.

## Prerequisites

An organization. A channel is required before a real conversation appears.
Do not use a customer phone number.

## Steps

1. Open **Chat**. Filters include **All** and **cerebronix-ai**.
2. Confirm the empty copy: **No conversations yet.**
3. Open **Contacts**. Use **+ Add** only with a dummy name such as
   `Jane Docs`.
4. Open the **Groups** tab on the same Contacts page. This is not
   ecommerce **Customer groups**.
5. Create a group named `Docs VIP`. Add only dummy contacts that have a
   phone or email.

![Apex Retail Global Chat empty state showing active inbox filters.](https://docs-cdn.cerebronix.com/guides/getting-started/04-chat-empty.png)

![Apex Retail Global Contacts view showing customer directory and group segmentation options.](https://docs-cdn.cerebronix.com/guides/inbox/01-contacts-empty.png)

All customer interactions maintain unified message histories linked to contact profiles. Contact groups allow operators to organize and segment audiences for proactive campaigns and automated workflows.
