When you finish this page, you have opened operator **Chat** and
**Contacts** and you know the empty states.

**Who:** `owner`, `admin`, or `developer`.

## Prerequisites

An organization. A channel is required before a real conversation appears.
Do not use a customer phone number.

## Steps

1. Open **Chat**. Filters include **All** and **cerebronix-ai**.
2. Confirm the empty copy: **No conversations yet.**
3. Open **Contacts**. Use **+ Add** only with a dummy name such as
   `Jane Docs`.
4. Open the **Groups** tab on the same Contacts page. This is not
   ecommerce **Customer groups**.
5. Create a group named `Docs VIP`. Add only dummy contacts that have a
   phone or email.

![Docs Demo Chat empty state. No conversations yet.](https://docs-cdn.cerebronix.com/guides/getting-started/04-chat-empty.png)

![Docs Demo Contacts empty state. Start adding new contacts with Add Contact.](https://docs-cdn.cerebronix.com/guides/inbox/01-contacts-empty.png)

Expected result: both pages load. Public conversation ids are Cerebronix
ObjectId hex values, not Chatwoot numeric ids. The group lists the same
people as the Contacts tab.

If Chat stays empty after you send a widget test, check the channel bind
and that you are on `cerebronix-dev.cerebronix.com`.
