When you finish this page, you have one test conversation in **Chat**.

**Who:** `owner`, `admin`, or `developer`.

## Prerequisites

A channel (web widget is enough) and an agent bound to it. Do not use a
real customer phone number.

## Steps

1. Open Chat in the sidebar, or open the web widget from Channels.

![Docs Demo Chat empty state. No conversations yet. Filters All and cerebronix-ai.](https://docs-cdn.cerebronix.com/guides/getting-started/04-chat-empty.png)

2. After a channel exists, send a short dummy message such as
   `Docs Demo test`. Do not use a real phone number.
3. Confirm the thread appears in **Chat**.

Expected result: the empty state goes away after the first test
conversation. Public ids are Cerebronix ObjectId hex values.
Public conversation ids are Cerebronix ObjectId hex values, not Chatwoot
numeric ids.

If the widget does not connect, check the channel bind and that you are
on `cerebronix-dev.cerebronix.com`, not `localhost`.
