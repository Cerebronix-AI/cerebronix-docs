---
title: Create or bind an AI agent
description: Open AI Agents and create or bind an agent.
---

When you finish this page, you have an agent in **AI Agents**, or you
know the empty state.

**Who:** `owner` or `admin`.

## Prerequisites

An organization. A knowledge source is optional for create, required
before you expect grounded answers.

## Steps

1. In the sidebar, open **AI Agents**. A new org already has **Default
   Agent** (`ACTIVE`) with no data sources bound.

![Docs Demo AI Agents list. Default Agent is ACTIVE with no data sources bound. + New Agent is in the header.](https://docs-cdn.cerebronix.com/guides/getting-started/03-agents-default.png)

2. Click **Edit** on Default Agent, or **+ New Agent**. Set instructions
   on the agent form.
3. Bind the agent to a channel after the channel exists.

Expected result: **AI Agents** lists the agent. Public `GET /agents` on
Port B can list it after you mint a Growth key.
