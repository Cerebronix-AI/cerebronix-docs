title: What Cerebronix is
description: Overview of the unified Cerebronix AI Platform and operator console.
---

Cerebronix is a unified enterprise conversational AI and automation platform. It brings together data ingestion, autonomous AI agents, omnichannel customer engagement (WhatsApp, Instagram, Web Widget), and native commerce into a single, cohesive operator interface.

This documentation portal provides operator guides and configuration instructions for managing your organization's AI capabilities. For programmatic integration, API keys, and SDK contracts, visit the Developer Platform.

## Platform Access

| Area | Access URL | Description |
|---|---|---|
| Cerebronix Console | [cerebronix.com](https://cerebronix.com) | Manage organization settings, AI agents, knowledge sources, communication channels, and billing. |
| Developer Portal | [developer.cerebronix.com](https://developer.cerebronix.com) | Access OpenAPI contracts, REST endpoints, webhooks, and Model Context Protocol (MCP) documentation. |
