---
title: Add a knowledge source
description: Open Data Sources and add a URL or file.
---

When you finish this page, you have opened **Data Sources** and added one
source, or you know the empty-state limit.

**Who:** `owner`, `admin`, or `developer`.

## Prerequisites

An organization. Free plans allow one data source.

## Steps

1. In the sidebar, open **Data Sources**.
2. Add a public URL or upload a small dummy file. Do not upload customer
   PII.
3. Wait until the source shows as ready. If index fails, retry once. If it
   still fails, note the source type and stop.

Expected result: dashboard **Data sources** count moves from `0 / 1` (Free)
to `1 / 1`.
