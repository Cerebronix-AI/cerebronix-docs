When you finish this page, you know which role an invite writes and where
that grant lives.

**Who:** `owner` or `admin` can grant org roles. A new invite writes
`developer` + `member`. Creating the organization writes `owner` +
`member`. `member` is session Oathkeeper only — not a public API role.

## Roles

| Role | Satisfies |
|---|---|
| `owner` | owner, admin, developer, viewer |
| `admin` | admin, developer, viewer |
| `developer` | developer, viewer |
| `viewer` | viewer |
