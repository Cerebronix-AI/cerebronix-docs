---
title: Organizations and roles
description: owner, admin, developer, viewer, and legacy member.
---

An organization is the tenant boundary for credits, agents, channels, and
the public API. One Kratos user can belong to more than one organization
through the org switcher.

| Role | Written when | Public API |
|---|---|---|
| `owner` | You create the organization | Yes |
| `admin` | Granted later | Yes |
| `developer` | Default on invite | Yes |
| `viewer` | Granted later | Read-only |
| `member` | With owner or invite | Session only |

Effective public permission is role ∩ scopes ∩ `PublicAPI` entitlement.
Free and Starter cannot mint keys.
