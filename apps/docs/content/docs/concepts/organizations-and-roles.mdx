---
title: Organizations and roles
description: owner, admin, developer, viewer, and legacy member.
---

An organization is the tenant boundary for credits, agents, channels, and the public API. A single user account can belong to multiple organizations and switch between them using the organization switcher in the navigation bar.

| Role | Assigned When | Public API Access |
|---|---|---|
| `owner` | Creating an organization | Full administrative access |
| `admin` | Promoted by owner | Administrative access |
| `developer` | Assigned on team invite | Agent, source, and API access |
| `viewer` | Assigned on team invite | Read-only access |
| `member` | Default organization membership | Console-only access |

Effective public permission is role ∩ scopes ∩ `PublicAPI` entitlement.
Free and Starter cannot mint keys.
