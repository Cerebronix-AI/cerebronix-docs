---
title: Agents, knowledge, and channels
description: How agents, data sources, and channels relate.
---

A **data source** is what the agent can read. A **channel** is where a
customer talks. An **agent** is the configuration that sits between them
(instructions, binds).

Configure your data sources and communication channels first, then bind them to your AI Agent to enable grounded, context-aware customer responses. Programmatic dialogue execution via the Public API consumes organization credits according to model usage.
