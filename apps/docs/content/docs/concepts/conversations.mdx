---
title: Conversations
description: Unified conversation threading and omnichannel inbox management.
---

The Cerebronix **Chat** interface provides an omnichannel unified inbox for operator oversight, agent interaction monitoring, and human-in-the-loop takeover across all connected customer communication channels (WhatsApp, Web Widget, Instagram, and more).

All conversations maintain continuous message histories and attribution linked to customer contacts. Conversation threads are referenced by their unique hexadecimal identifiers across both the operator console and the Developer Public API.
