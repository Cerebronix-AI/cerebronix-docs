title: Conversations
description: Cerebronix-owned conversation ids. Chatwoot is an implementation detail.
---

Operator **Chat** shows organization conversations. Public clients use
Cerebronix ObjectId hex ids. Chatwoot numeric ids in a public URL are
`404`.

Do not teach Chatwoot conversation ids as the product contract.
