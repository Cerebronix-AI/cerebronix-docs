---
title: Environments
description: cerebronix-dev versus production. Cookie domain is not localhost.
---

| Environment | Operator console | Session API | Public API |
|---|---|---|---|
| Local | `https://cerebronix-dev.cerebronix.com` | `:8000` / `api.cerebronix.com` in prod terms | `:8010` / `https://public-api.cerebronix.com` |
| Production | `https://cerebronix.com` | `https://api.cerebronix.com` | `https://public-api.cerebronix.com` |

Local session cookies are scoped to `cerebronix-dev.cerebronix.com`.
`localhost:3000` does not receive them.

The public API does not use cookies. Mint a Bearer token. See the
developer Quickstart.
