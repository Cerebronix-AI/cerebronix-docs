## Closed Beta waitlist after you verify email

Email verification is not the same as admin enable. An enabled user can
still hit a cached `enabled: false`. Ask an admin to enable the account,
then sign in again.

## Public `/v1` returns 404

Bare `GET /v1/conversations` is 404. Org-scoped routes live under
`/v1/organizations/{org}/...`. Unauthenticated `/v1/me` is 401, not 404.

Use `https://public-api.cerebronix.com`. Do not call
`api.cerebronix.com` as the public API.

## Free org cannot mint a key

`403 public_api_disabled` is expected on Free and Starter. Upgrade to
Growth or higher.
